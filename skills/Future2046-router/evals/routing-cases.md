# 入口行为案例

| 输入 | 预期 |
|---|---|
| `$future2046 新手入门` | 介绍可提交的任务与已安装能力，不启动少走弯路。 |
| `$future2046 请把这篇视频文稿拆成误区卡` | 发现少走弯路，完整读取其规则；按 V4 流程执行，不能直接写卡。 |
| `$future2046-avoid-pitfalls 请拆解指定文稿` | 允许绕过入口直接调用叶子 Skill。 |
| 一项任务先要整理素材、再要拆误区，且两项能力均已安装 | 先取得整理结果，再交给少走弯路；前一项未交付不得冒充已完成。 |
| 用户只问“有哪些 Skill 适合我” | 给推荐与理由，不开始业务处理。 |
| 输入要求与现有已安装 Skill 均不匹配 | 说明缺口或给普通回答，不伪称调用。 |
| 正式 Skill 只在目录快照中出现但未安装 | 标记不可用，说明安装方式，不执行。 |
| 叶子 Skill 的 `SKILL.md` 被改动且目录快照未更新 | 标记定义不一致，不静默使用旧摘要。 |
