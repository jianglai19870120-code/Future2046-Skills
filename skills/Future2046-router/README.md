# Future2046 入口

在 Codex 对话中输入 `$future2046`，随后写下任务、材料或希望得到的结果。入口会从同级已安装的 Future2046 Skill 中选择适用能力，在当前对话继续处理。第一次使用可输入 `$future2046 新手入门`。

知道要使用哪个 Skill 时可以直接调用它。入口只负责选择与交接；业务方法、写入权限和质量门禁由具体 Skill 管理。候选目录由仓库注册表生成，单独安装入口而未安装成员 Skill 时，入口会报告缺少的能力。

安装、更新与工作区准备见[仓库新手入门](../../docs/新手入门.md)。
