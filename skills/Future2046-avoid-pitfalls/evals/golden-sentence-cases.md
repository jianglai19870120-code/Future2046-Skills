# 核心金句观点评测

## 通过案例

以下观点不要求使用“以为”，但必须与对应标题、文件名核心标题完全一致，并由误区场景和原文依据共同支持：

```text
追求播放量和粉丝量不如追求停留时长和深度互动
大部分人视频没流量根本不是因为表现力差
```

## 拒绝案例

以下内容只有主题、口号或泛泛建议，不能作为核心金句：

```text
内容要有价值
流量不是一切
用户体验很重要
表达要真实
```

## 一致性拒绝案例

- 一级标题、误区观点和文件名核心标题不一致；
- 索引 `title` 和 `viewpoint` 不一致；
- 观点写成提问、建议或模糊可能性；
- 观点加入原文没有的原因、对象或结果；
- 观点只支持口播创作细节，不支持核心判断；
- 为了凑字数加入无依据内容。

## 审核重点

观点可以是原文支持的纠偏结论，但必须仍然对应同一误区，保留核心变量或因果方向，且不能退化为脱离场景的漂亮口号。

## 全场景语义覆盖案例

### 应拒绝：只提取局部机制

场景：只追流量、重复旧内容、没有新实践和新认知，最终导致 IP 停止成长。

```text
流量增长不等于IP持续成长
```

拒绝原因：只表达流量和成长的关系，遗漏了错误行为、关键条件和形成结果的完整问题链。

### 应通过：覆盖主要行为和结果

```text
只追流量不做实践，IP就不会持续成长
```

观点可以使用其他自然表达，但必须同时覆盖场景中的主要错误行为、关键条件或最终结果；不能为了更短退化成单个指标关系。
