# 分类避坑指南评测案例

## 应通过

- 批次取得 `completed` 且最终校验通过后，在对话中询问是否生成指南。
- 用户选择一个分类时，只生成该分类的 Word 文件。
- 用户选择多个分类时，按用户给出的顺序逐个生成、逐个审核、逐个落盘。
- 每章编号从 1 开始，空篇章省略，卡片标题和误区场景来自正式卡片。
- 旧 Word 文件存在时，先备份，再原子替换。

## 应拒绝

- 单篇源稿刚完成但批次尚未结束时提前询问。
- run 为 `paused`、`failed` 或最终校验失败时生成指南。
- 索引分类与正式卡 frontmatter 分类不一致。
- 索引指向的正式卡不存在，或卡片状态不是 `active`。
- 指南混入其他分类、重复卡片、缺失卡片或不连续编号。
- 审核未通过时覆盖已有正式 Word 文件。
- 没有 LibreOffice 或没有逐页检查 PNG 时，`visualReview` 保持 `pending`，不得正式替换。

## 运行边界

- 生成器只写 `record_root/guides/staging/`。
- 审核报告和缓存只写 `record_root/guides/`、`record_root/cache/`。
- 正式 Word 只能由审核通过后的晋级程序写入工作区根目录。
- 源稿、正式误区卡、索引和历史运行记录不得被指南生成流程改写。
