# 流程失败案例

这些案例验证文件处理、确认交互和落盘门禁，不生成正式误区卡。

## FAIL-001｜文件无法读取

### 条件

用户指定不存在或无法读取的源文件。

### 预期行为

- 报告文件不存在或无法读取的原因；
- 列出可用候选（如果能找到）；
- 不校正、不拆解、不写卡、不写完成记录。

## FAIL-002｜不支持格式

### 条件

源知识库中出现不在 `.md`、`.txt`、`.docx`、`.pdf` 范围内的文件。

### 预期行为

- 标记为“不支持格式”；
- 不伪造文字提取结果；
- 不生成误区卡。

## FAIL-003｜用户确认前

### 条件

未指定具体文件，扫描发现多篇待处理文稿，但用户尚未选择全部、单篇或取消。

### 预期行为

- 只展示检测清单；
- 不校正、不覆盖、不生成卡片、不写处理记录。

## FAIL-004｜审核连续失败

### 条件

候选卡经过3次独立审核仍未通过。

### 预期行为

- 不写正式卡；
- 写入 `status: "failed"` 和失败原因；
- 暂停批次，不启动下一篇。

## FAIL-005｜零卡文稿

### 条件

全文完成阅读，但没有候选通过五道判定门槛。

### 预期行为

- 不生成空卡片文件；
- 经独立审核确认无合格误区；
- 写入 `cardCount: 0`、`status: "completed"`；
- 批量任务完成记录写入后才可进入下一篇。

## FAIL-006｜前一篇未提交不得启动下一篇

### 条件

第 N 篇仍存在 `active-run.json`、状态为 `in_progress`，请求启动第 N+1 篇。

### 预期行为

- `stage_receipt.py start` 返回失败；
- 不创建新的 run；
- 不生成下一篇卡片；
- 不修改索引和处理记录。

## FAIL-007｜正式目录提前出现卡片

### 条件

当前 run 尚未完成独立审核或最终去重，但 `02_误区卡片` 已出现新文件。

### 预期行为

- 严格校验失败；
- 当前 run 不得提交为 `completed`；
- 报告孤立正式卡片路径；
- 必须先恢复到 staging 或由用户决定如何处理。

## FAIL-008｜伪造完整阶段回执

### 条件

使用旧的批量回执脚本一次性写入 14 个阶段。

### 预期行为

- 旧脚本拒绝执行；
- 必须使用 `stage_receipt.py` 逐阶段推进；
- `validate_pipeline.py --require-full-run` 不接受旧版或事后补录记录。

## FAIL-009｜阶段时间不递增

### 条件

所有阶段使用相同时间戳，或后阶段早于前阶段。

### 预期行为

- 严格校验失败；
- 不得写入 `completed`；
- 不得解锁下一篇。

## FAIL-010｜只有回执没有阶段产物

### 条件

提交 `evidence-json`，但没有对应的 artifact manifest、输入哈希和输出产物。

### 预期行为

- `stage_receipt.py` 拒绝写入回执；
- 不得进入下一阶段；
- 不得提交正式卡片；
- 不得写入 `completed`。

## FAIL-011｜旧卡复制为新初稿

### 条件

重跑时把 `02_误区卡片` 的正式旧卡直接复制到当前 run 的 draft 目录。

### 预期行为

- `card_draft_generation` 产物契约失败；
- 必须从当前源稿和候选判断重新生成 draft；
- 旧卡只能作为只读参考，不能作为本次初稿。

## FAIL-012｜审核拒绝被错误地当作字段缺失

### 条件

独立审核真实判定为 `rejected`，并指出 `meaningPreserved: false` 或其他口播问题。

### 预期行为

- 审核回执应允许保留真实的布尔失败证据；
- `rejected` 不得进入最终去重和正式提交；
- 需要返修复审，或由用户选择 `--fail` 暂停批次、`--skip` 放弃该稿。
# 识别稿校正失败门禁

## 缺少语义分段回执

如果 `transcription_normalization` 产物没有 `paragraphReflow`，或缺少
`changed`、`beforeParagraphCount`、`afterParagraphCount`、`boundaries` 任一字段，机器校验必须失败，不能进入误区候选识别。

## 段落数量不一致

如果 `afterParagraphCount` 与校正 Markdown 实际段落数不一致，机器校验必须失败；即使错别字和标点已经校正，也不能继续生产。
