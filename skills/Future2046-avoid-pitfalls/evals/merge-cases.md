# 候选合并案例

## MERGE-001｜同一错误的不同说法

### 输入文本

老板觉得访谈不费时间，所以认为可以一直靠访谈做内容。他后来又说，只要老板聊得自然，长期合作就不用重新设计内容。实际问题都是把访谈早期的轻松当成长期方法。

### 预期结果

- 只生成1张卡；
- 合并“访谈省时间”和“自然聊天可以长期合作”两个表述；
- 不重复生成两张内容相同的卡。

## MERGE-002｜不同阶段、不同误区

### 输入文本

老板早期觉得拍视频别太折腾自己，所以选择访谈。做了一段时间后，访谈内容开始重复，用户并不关心老板反复讲的产品和理念；他却又认为只要把产品讲清楚，用户就会主动关注。后来他发现，内容必须站在用户角度表达。

### 预期结果

- 可以生成2张卡；
- 第一张针对“把短期省事当成长期方法”；
- 第二张针对“把自我表达当成用户需要的内容”；
- 两张卡不得因为都涉及访谈而错误合并。

## MERGE-003｜错误与后果区分

### 输入文本

团队认为短期数据好，所以继续使用同一形式。后来用户不再关注，团队发现内容没有面向用户设计。

### 预期结果

- 原则上生成1张核心误区卡；
- “用户不再关注”作为问题证据，不单独拆成第二张卡；
- 卡片核心仍是把短期数据当成长期方法依据。
