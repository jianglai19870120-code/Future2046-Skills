# 误区观点与原文依据规则

本文件专门规定两件事：误区观点怎样在 24 个汉字以内表达完整，以及原文依据怎样保留足够上下文。误区判断门槛仍见[误区判断规则](misconception-judgment-rules.md)，审核执行见[独立审核规则](independent-review-rules.md)。

## 一、误区观点

### 1. 必须表达完整错误判断

误区观点必须同时包含：

```text
犯错对象或决策主体
+
错误认知、错误做法或错误判断
+
错误认知中的因果或判断方向
```

它写的是犯错者当时相信什么，不是作者最后得出的正确结论。以下内容不合格：

```text
故事很重要
短视频要讲故事
访谈不能获客
专业表达没用
```

这些要么只是主题，要么只是纠偏结论，无法说明“谁把什么错误地当成了什么”。

优先考虑这些语义关系，但不强制所有卡片套同一模板。必须根据具体语义选择句式，不能把所有观点都改写成“以为……”：

```text
把 A 当成 B
以为 A 就能 B
觉得只要 A 就会 B
相信 A 本身就等于 B
认为做了 A 就不需要 B
把短期结果当成长期方法
```

还可以使用：

```text
只要 A 就会 B
A 本身就等于 B
做了 A 就不需要 B
否定性错误判断
条件错配判断
因果倒置判断
主体归因错误
```

阶段产物必须记录：

```json
{
  "viewpointPattern": "条件错配判断",
  "patternSelectionReason": "原文只说明该方法在特定阶段有效，人物却把它当成长期通用方案"
}
```

句式选择的目标是准确还原错误关系，不是追求表面多样化。比如“很多人以为跨过低谷期靠盲目努力”比直接复制“我注定会成为英雄”更能表达把努力本身当成解决方案的误区；但只有原文同时提供了相应行为、限制或结果证据时，才能这样概括。

### 2. 字数是上限，不是目标

- 只保留 24 个汉字以内的上限，不设置机械最低字数；
- 短句已经完整表达错误认知时可以保持短；
- 不能为了短而删掉关键对象、动作或因果关系；
- 不能只剩关键词、标签或模糊金句；
- 不能为了凑字数加入原文没有的判断；
- 表达完整优先于追求最短。

### 3. 原文贴近不等于原句摘抄

“贴近原文”指贴近原文的核心意思、错误机制和因果方向，不是把原文中的某一句话直接复制成误区观点。

观点提炼必须经过三层还原：

```text
原文事实或人物原话
→ 人物采取了什么做法、为什么这样做
→ 这个做法背后的可复用错误认知
```

例如，原文写某个人在低谷期把自己想象成英雄，并持续依靠自律和努力。不能只摘成：

```text
我注定要活成一个英雄
```

这只是人物当时说过的一句话，没有充分表达可供调用的误区机制。经过还原后，可以写成：

```text
很多人以为跨过低谷期靠盲目努力
```

但只有在原文确实呈现了低谷处境、持续努力，以及把努力本身当成解决方案的错误方向时，才允许这样概括。

具体规则：

- 原文有完整错误认知时，保留关键语义，但可以改写为更完整、可复用的口语判断；
- 原文只有行为、理由和结果时，先还原行为背后的错误判断，再生成观点；
- 第一人称自述不能机械保留“我”，要判断它能否归纳为“很多人”“人很容易”或某类行为主体；
- 只有原文证据支持普遍化时，才使用“很多人”等泛化主体；
- 不得因为追求贴近，就把人物自我宣言直接当成最终误区观点；
- 不得为了概括而加入原文没有的错误机制；例如原文只有“努力”，不足以支持“盲目努力”时，必须先核对是否存在忽视限制、缺乏检验或努力无效的证据。

判断标准是：读者只看误区观点，就能知道“错误的人在什么方向上想错了”，而不是只知道原文里出现过哪句话。

### 4. 句式和语气

误区观点应当是一句完整、笃定、自然的口语判断，尽量贴近原文。通常不超过一个逗号，不使用分号，不并列多个误区，不加入解释、后果或纠偏建议。除非原文本身明确不确定，不使用“可能、也许、似乎”等削弱判断的词。

观点生成优先级为：

```text
原文明确错误判断
> 原文错误行为和错误理由
> 原文前后反转
> 原文问题结果
> 基于原文的最小重组
> 必要时的少量补写
```

原文已有完整错误判断时，保留核心语义、错误对象和因果方向，但不要求逐字复现。原文没有完整句子时，必须根据行为、理由、结果和反转还原背后的错误判断，再进行最小必要重组；“最小必要重组”不是换几个词，而是把事实还原成完整误区。不得变成脱离原文的新观点。

### 4. 观点充分性检查

在初稿进入口语化润色和独立审核前，逐候选记录并检查：

```json
{
  "viewpointQuality": {
    "isMistakenBelief": true,
    "hasErrorObject": true,
    "hasErrorJudgment": true,
    "hasCausalDirection": true,
    "semanticComplete": true,
    "sourceClose": true,
    "tooCompressed": false,
    "isCorrectionConclusion": false,
    "sentenceCount": 1,
    "commaCount": 0,
    "characterCount": 18
  }
}
```

以下任一项不通过，必须退回重写或淘汰候选：只有主题、只有标签、只有正确建议、只有纠偏结论、关键对象缺失、关键因果缺失、过度压缩、多个并列误区或超过 24 字。

## 二、原文依据

### 1. 证据必须覆盖完整判断链

原文依据至少覆盖：

```text
认知证据 + 问题证据
```

必要时再补充纠偏证据。认知证据证明犯错者相信什么，问题证据证明这种认知或做法出现了什么局限、结果或失败，纠偏证据说明原文最终转向哪里。

### 2. 按最小完整上下文截取

截取范围优先级为：

```text
完整句子 → 完整段落 → 连续相邻段落
```

- 一个完整句子已同时包含认知和问题时，引用该完整句子；
- 认知和问题在同一段时，引用完整段落；
- 认知、问题和纠偏在相邻段落时，连续引用这些段落；
- 不从远距离位置拼接关键词，不截断句子、转折或因果关系；
- 不设置机械字数上限，以“读者脱离全文仍能理解误区”为准；
- 段落很长时只在完整句子边界截取，并保留完整起因、判断、问题和必要转向。

最终卡片使用连续引文：

```markdown
## 原文依据

> 完整的原文句子。
>
> 连续的下一句或相邻段落。
```

关键词片段、相距很远的断裂片段和为了变短而删除关键转折的引文不合格。创作的案例、人物、数字和口播细节不能替代原文依据。

### 3. 内部证据记录

在阶段产物中记录，不要求展示在最终卡片：

```json
{
  "sourceEvidence": {
    "paragraphIds": [6, 7],
    "startSentence": 1,
    "endSentence": 5,
    "roles": {
      "cognitive": true,
      "problem": true,
      "correction": true
    },
    "isContinuous": true,
    "contextComplete": true
  }
}
```

## 三、独立审核新增项

审核必须额外确认：观点不是压缩标签、仍然是犯错者相信的判断、保留原文核心词和因果方向；原文依据是连续上下文，覆盖认知证据和问题证据，没有关键词拼接或截断因果关系。观点过短导致语义不完整，或证据过短无法独立支撑观点，都必须退回。

## 四、反例评测

第 1 篇只谈故事、人生意义和创作主题，没有明确错误对象、错误判断及内部纠偏链，合法结果是零卡。不得生成“故事很重要”“故事是最好的文案”“人生需要故事”。

第 2 篇只展示“通感”写作手法示例，没有错误行为、问题结果、反转或纠偏，合法结果是零卡。不得生成“文案要有通感”“通感能写好文案”“要学会通感”。
