# 误区卡模板

每张卡使用 YAML frontmatter 管理机器可检索元数据，再保留核心标题、一条误区观点、一段口语化误区场景口播稿和原文依据。编号、标签、分类和源文件地址不得放进一级标题。

```markdown
---
card_id: "MISC-000003-01"
category: "新媒体" # 只能是新媒体、创业搞钱、成长逆袭或空字符串
tags:
  - "标签1"
  - "标签2"
source_address: "01_源知识库/视频文稿/经纬 (2).md"
---

# <核心标题>

## 误区观点

<一句不超过 24 个汉字、自然口语化、笃定完整的核心金句。新 V4 run 必须先从完整误区场景和原文依据生成 sceneSemanticMap，再提炼覆盖主要对象、错误行为或错误归因、关键条件与问题结果核心语义的观点；24字是上限，不是越短越好。可以概括错误认知，也可以在原文充分支持时写成纠偏判断；不得写成局部指标、泛泛口号、无依据建议或脱离场景的金句。>

## 误区场景

<将常见处境、错误做法、错误理由、问题结果和正确转向整合成 2—4 个自然口播段落。默认直接面对听众说话，允许使用“你”“很多人”、自然反问、停顿和长短句变化。五个环节要各自提供新信息，不得出现“原稿里的老板”“源稿中的老板”“作者提到”等来源回指。原文有对应表达时优先保留并轻微改写，原文只有意思时基于原意重组，原文缺少必要环节时可以合理补写或创作。创作细节不得冒充原文事实或与原文核心事实冲突。>

## 原文依据

> <支持误区观点的连续原文引句。>
```

原文依据必须直接支持核心金句，不要求逐项证明口播中的合理创作细节。`canonicalViewpoint`、一级标题、`误区观点`、索引 `title`、索引 `viewpoint` 和文件名核心标题必须逐字一致。`category` 字段必须存在，无法明确归类时写空字符串。`tags` 必须是 1-3 项数组，`source_address` 必须是工作区相对路径。文件名默认格式为：`<原文稿名>_<canonicalViewpoint>.md`；如果标题包含 Windows 不允许的文件名字符，必须暂停报告，不能静默改写观点。
