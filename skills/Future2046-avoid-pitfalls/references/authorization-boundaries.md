# 运行授权边界

## 默认只读动作

- 扫描源知识库并计算文件状态；
- 读取源稿、工作区配置、正式卡片和索引；
- 比较候选与历史卡片；
- 在当前 run 内生成阶段产物、审核请求和临时 staging 文件。
- 生产产物只能写入工作区 `record_root`；禁止写入用户目录、系统 Temp、仓库根目录或 Skill 包目录。
- 审核回执和提交清单必须通过 Skill 包内正式脚本生成，不得动态创建临时 Python 脚本。

## 需要用户明确处理范围的动作

- 批量处理全部待处理文稿；
- 校正并覆盖已有 Markdown 源稿；
- 对已存在正式卡片进行重跑或覆盖；
- 把 Excel 行物化成 Markdown；
- 改变分类、标签或来源元数据。

## 正式落盘门禁

正式卡片、索引和 `processing-log.jsonl` 只能由 V4 提交流程写入。校正稿、初稿、口语化稿和审核报告必须先在当前 run 中完成并通过独立审核和最终去重。

## 不自动执行的动作

- 删除源稿、卡片、归档或处理记录；
- 把个人工作区复制进 Skill 包；
- 上传 GitHub、创建 Release、发布公开压缩包；
- 把源稿内容发送给未获用户授权的外部服务。
