# 强口播与对话感润色规则

## 适用时点

误区初稿完成后、独立审核前，必须单独执行一次强口播重写。它只改写 `## 误区场景`，不改标题、标签、误区观点、原文依据、编号或文件名。

先保存 draft，再另存 polished；两份文件及清单均位于当前 run 的产物目录。由机器计算并核对两者 SHA-256，逐字节比较场景之外的内容。存在误区卡时，polished 场景默认必须与 draft 不同；只有场景极短、原文已经是成熟口播稿且独立审核者明确批准时，才允许记录 `unchangedReason`。润色后如再修改卡片，原审核哈希失效，须重新润色和审核。

## 目标

- 默认直接面对听众说话，优先使用“你”“很多人”“你在……的时候”等自然主体；
- 让文字像真人面对镜头解释问题，有对话感和口播节奏；
- 使用笃定但不生硬的语气，长短句交替；
- 可以使用自然反问、停顿和“你会发现”“问题就在这里”“所以真正要做的是什么呢”等口语连接；
- 删除机械、书面、模板化和分析腔表达；
- 让听者自然理解处境、错误、问题和正确转向。

最终标准是：读起来像一个人正在面对另一个人解释问题，而不是在写审核报告或方法总结。

## 五段写作职责

最终保留 `## 误区场景` 栏目，但允许使用 2—4 个自然段。写作时仍需按以下五个职责组织，五个职责不可互相替代，也不能重复表达同一内容：

1. **常见处境**：只交代谁在什么任务、阶段或压力下遇到问题。只写进入误区的入口，不提前解释原因或结果。
2. **错误做法**：写这个人具体做了什么，或选择了什么做法。必须是可观察的动作，不要只写“他有误区”。
3. **错误理由**：解释他为什么会觉得这样做合理，写出当时的直觉、期待或判断。不要再次重复错误动作。
4. **问题结果**：写这种做法实际造成的落差、局限或结果。只说明问题，不在这里提前展开正确方案。
5. **正确转向**：明确应该把注意力、内容或行动转向哪里，并用一句有力度的收束句结束。不能只写“所以要改变”，必须说清改变方向。

每个自然段只回答一个主要问题，但不要求一个段落只承担一个内部职责：

```text
在什么情况下？→ 做错了什么？→ 为什么会这么做？→ 具体哪里不行？→ 应该转向哪里？
```

如果某一段无法提供新的信息，就删除，不用同义句填充。五段之间要形成因果推进，而不是五次重复“专业不等于信任”这类结论。

## 口播主体与来源回指禁令

- 不得出现“原稿里的老板”“源稿中的老板”“作者提到”“文中这个人”“受访者后来”等分析性来源回指；
- 不得在口播中解释自己正在改写原文，也不得让听者知道这是一张拆解卡；
- 可以使用“很多老板”“一个专业型老板”“你在做内容时”等自然主体；
- 如果需要具体人物，使用脱离原稿的泛化人物，不保留可识别的人名、原稿身份或“后来她……”这种追述结构；
- 原文中的事实证据只放在“原文依据”，不在“误区场景”里用来源说明重复证明。

## 口播自检

润色完成后逐项检查：

- 删除所有原文、源稿、作者、受访者、文中人物等来源指代；
- 错误动作只出现一次，错误理由不重复动作；
- 问题结果具体可感，不能只写“效果不好”；
- 正确转向是明确动作或判断，不是空泛鸡汤；
- 全文读起来像一个人直接对听众解释，而不是审核报告或案例复盘。

## 允许的创作

场景的五个环节不要求都存在原文原句。应当按环节判断原文覆盖程度：

1. 原文有对应表达时，保留原文核心词语、事实、人物处境、行为和判断，只做轻微改写、重组、断句和口语化处理；
2. 原文没有完整句子但有明确意思时，可以根据该意思重新组织表达；
3. 原文缺少某个必要环节时，可以在原文核心方向上补写泛化处境、动作或表达性结论；具体数字、时间、客户反应和结果只能在有原文依据时作为事实呈现，虚构示例须明确为假设且不能冒充来源事实；
4. 创作内容必须服务于当前误区，不得改变原文的核心方向、误区依据、人物行为、事实结果或纠偏逻辑；
5. 创作内容不得引入另一个无关误区，也不得被写成原文、作者或受访者明确说过的事实。

因此，强口播润色不是完全脱离原文重写，也不是机械逐字复述，而是：

```text
原文有对应内容：优先保留并轻微改写
原文只有意思没有完整句子：基于原意重组
原文缺少必要环节：允许合理补写
```

## 强口播重写门槛

不允许只做以下动作：

- 替换几个词；
- 增加“其实”“但是”“所以”等连接词；
- 只把“他”改成“你”；
- 只调整标点或拆短句；
- 原样复制 draft。

polished 至少应体现两项以上真实表达变化：重新组织句子节奏、加入自然听众主体、增加口语推进、使用自然反问或停顿、拆分为更适合朗读的段落、删除报告腔。不得为了满足形式强行加入无关故事或事实。

建议的口播推进方式：

```text
把听众带入处境
→ 说出他为什么会这样想
→ 用“但问题是”“你会发现”等转出落差
→ 用反问或自然停顿推进
→ 给出具体转向并有力度地收束
```

## 目标示例

说明式初稿：

```text
人在经历低谷和一地鸡毛的时候，很容易把自己重新写进一个英雄剧本里，觉得只要相信自己注定不凡，就能一直往前走。更稳妥的做法是回到具体行动和结果上。
```

强口播 polished：

```text
人在经历低谷、生活一地鸡毛的时候，特别容易把自己想象成一个故事里的英雄，觉得只要相信自己这辈子注定不平凡，就能一直往前走。

这种信念啊，有时候确实能让你撑下去。但如果你真的觉得自己注定会成为英雄，那就很容易把自己的想象当成现实，反而忽略了眼前真正的问题和自己身上的限制。

所以，更好的做法是什么呢？就是保留这股想要往上走的劲儿，但同时也要回到具体的行动和结果上，重新看看自己到底走到了哪一步。
```

示例只用于说明口播节奏，不得替代当前源稿的事实依据或误区判断。

`原文依据` 必须回到源文稿，不能用创作内容替代。创作内容不需要逐项出现在原文中，但必须与原文核心意思相容，且不能冒充原文事实。
