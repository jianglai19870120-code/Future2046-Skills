# 少走弯路 Skill

当前版本：`1.3.2`

生产流程保留完整 V4 阶段证据，但实际执行按六个质量节点组织，减少重复读取、重复启动审核和重复扫描历史卡。详见 [执行效率规则](references/execution-efficiency-rules.md)。

这是一个面向行业避坑的误区知识提炼 Skill。它可以帮助你提前识别行业常见坑，避坑、少走弯路。它既可以把一篇完整文字材料转成可调用的误区卡，也可以围绕某个具体行业持续整理文章、书籍、访谈、视频文稿、新闻稿和 Excel 文案，建立可检索的行业避坑知识库。

## 主要能力

- 支持围绕具体行业持续沉淀常见坑、错误认知和需要避开的做法；
- 帮助你在进入或经营某个行业前识别常见坑，减少试错和重复走弯路；
- 保留每张卡的行业分类、标签、来源地址和原文依据，形成可复用的行业内容资产；
- 先扫描新增或变化源稿；
- 校正错别字、断句、标点并按语义重新分段；
- 依据原文内部证据识别独立误区；
- 经过五道判断门槛、文内去重和全局去重；
- 独立生成口语化场景并进行隔离审核；
- 使用 V4 阶段产物、哈希和可恢复提交，严格逐篇落盘。

## 什么时候用

- 想了解某个行业有哪些常见坑；
- 想把一个行业的书籍、文章、访谈和视频文稿集中整理；
- 想从高质量行业资料中提炼反复出现的错误认知；
- 想建立自己的行业避坑卡片库；
- 想以后根据某个行业问题快速检索对应误区卡。

例如，你正在做教育培训行业，可以这样使用：

```text
我正在做教育培训行业，请读取源知识库中的书籍、访谈和视频文稿，
提炼这个行业常见的错误认知和容易踩的坑。
```

如果你正在研究餐饮行业，也可以批量处理：

```text
我正在研究餐饮行业，请把这个文件夹中的资料按顺序拆解，
建立餐饮行业避坑误区卡。
```

## 使用前提

工作区根目录必须有 `workspace.yaml`。可以从发布包中的 `workspaces/少走弯路工作区` 复制并改名，也可以为自己的目录创建同样的配置。

Skill 源包不包含任何个人源稿、误区卡片或处理记录。详细规则从 [SKILL.md](SKILL.md) 开始，运行权限边界见 [authorization-boundaries.md](references/authorization-boundaries.md)。

## 输入与执行

复制发布包中的 `workspaces/少走弯路工作区` 为自己的工作区，放入 Markdown、TXT、DOCX、PDF 或 Excel 资料。首次使用 Excel 时先安装 `python -m pip install -r requirements.txt`；只处理文本时可以不安装 Excel 依赖。调用 `$future2046-avoid-pitfalls` 并提供工作区路径。未指定文件时先展示待处理清单，用户确认范围后依次处理。

Excel 中每行“作品文案”先形成独立 Markdown；校正识别错误和语义分段后，按稳定源稿队列识别候选、通过五道门槛、文内及全局去重、生成初稿、独立润色、独立审核、正式提交并验证。当前篇取得合法终态后才能开始下一篇。详见 [Excel 规则](references/excel-materialization-rules.md)、[源稿队列规则](references/source-queue-rules.md)、[校正规则](references/transcription-normalization-rules.md)和[产物契约](references/artifact-contracts.md)。

行业资料越多，能够沉淀的避坑卡片越丰富；但每张卡仍必须有原文内部证据，并经过完整 V4 流程、独立审核和全局去重。行业避坑知识库是可调用的内容资产，不等同于外部事实数据库。

## 输出与调用

正式卡片落在工作区配置的 `card_root`（当前为 `02_误区卡片`），含 `card_id`、分类、标签、源地址、误区观点、口语化场景和原文依据；格式见[卡片模板](references/misconception-card-template.md)。按观点检索时只读取已有卡片，遵守[检索规则](references/card-retrieval-rules.md)。索引和阶段记录在 `workspace.yaml` 配置的 `record_root`（当前为 `98_处理记录`），不得创建替代目录。

## 常见暂停原因

审核未通过、去重不确定、索引不一致或提交中断时，先检查当前 run 与错误报告；恢复操作见[处理记录规则](references/processing-log-rules.md)。不要手动删锁或直接编辑正式卡片。
