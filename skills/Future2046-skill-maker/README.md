# Skill 制作器

`$future2046-skill-maker` 用于创建、改进、测试和发布 Future2046 Skill。

## 适用场景

- 把重复出现的任务沉淀成新 Skill；
- 修复已有 Skill 的规则、流程或测试问题；
- 检查 Skill 的结构、版本、注册表和安装副本；
- 准备公开发布包或验证安装结果；
- 在用户明确授权后执行远程发布流程。

## 使用示例

```text
$future2046-skill-maker 我想把这个重复任务做成一个新的 Future2046 Skill。
```

```text
$future2046-skill-maker 检查这个 Skill 的版本、路由和安装副本是否一致。
```

## 运行要求

- Python 3.11 至 3.13；
- 能读取目标仓库和相关 Skill 文件；
- 发布任务需要用户明确提供远程仓库目标和授权范围；
- 发布前必须通过仓库结构、行为、公开范围和安装验证。

## 边界

本 Skill 不替用户决定业务定位，不读取未授权的私密资料，不自动推送远程仓库，也不把用户工作区数据纳入公开包。

## GitHub 上传边界

源码仓库上传项目文档、公开 Skill 包、测试、规则、脚本和必要的安装文件；不上传真实工作区资料、运行记录、密钥、本机配置、缓存、临时文件或 `dist/` 构建包。`dist/` 中的当前版本 ZIP 和 manifest 只作为 GitHub Release 附件上传。

完整的上传与排除清单见[发布与 GitHub 流程](references/publishing.md)。

完整规则见 [SKILL.md](SKILL.md)。
