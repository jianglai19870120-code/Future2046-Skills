# 验证与回退规则

## 验证层级

1. 结构校验：frontmatter、元数据、引用、脚本语法和注册表通过；
2. 行为测试：真实任务的输出和工具动作符合预期；
3. 回归测试：原有正确任务没有被破坏；
4. 安装验证：源目录、安装目录和发布包逐文件一致。

每层只报告实际执行过的检查。静态检查不能替代真实任务验证。

## 回退

写入前创建相关文件快照或确认 Git 回退点。回退只恢复本次批准范围，不删除用户工作区，不重置整个仓库，不覆盖无关改动。

## 发布阻断

出现敏感文件、个人路径、版本不同步、路由快照过期、安装文件不一致、测试失败或远程目标不明确时，停止发布并说明具体阻断位置。
