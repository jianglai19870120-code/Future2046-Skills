# Future2046 新手入门

Future2046 是一组在 Codex 对话中使用的 Skill。你可以直接说出手上的任务，让 `$future2046` 选择合适的能力；已经知道要用哪个 Skill 时，也可以直接调用它。

目前正式提供统一入口和少走弯路 Skill。这里介绍怎样开始、怎样更新，以及每个 Skill 适合处理什么。具体的执行规则留在各自的包内。

## 第一次怎么用

**先安装。** 准备 Python 3.11 至 3.13，下载并解压 Future2046 发布包，在解压后的根目录运行：

```powershell
python -m pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File .\tools\sync_codex_install.ps1
```

这会安装 `$future2046` 入口和当前所有支持 Codex 的正式 Skill。安装完成后，新建一个 Codex 对话，输入：

```text
$future2046 新手入门
```

入口会介绍当前已安装的能力。接下来，你可以直接提交自己的任务：

```text
我有一段材料，想知道能怎样处理：……
我想从这篇文章里找出错误认知：……
我已经有一批文稿，想逐篇拆成误区卡：……
```

例如：

```text
$future2046 这是一篇视频文稿，请帮我找出能独立成立的误区，并生成误区卡。
```

入口会根据任务选择已安装的 Skill，说明本轮安排，并在当前对话中继续处理。材料已经在对话中时，不必再发一次。

**需要保存文件时，准备工作区。** 少走弯路提供带说明和虚构示例的工作区模板，不包含个人资料。你可以在发布包根目录运行：

```powershell
Copy-Item -LiteralPath '.\workspaces\少走弯路工作区' -Destination (Join-Path $env:USERPROFILE 'Documents\少走弯路工作区') -Recurse
```

把自己的文稿放进复制后的工作区，再把工作区路径告诉 Codex。Skill 安装包保存能力；工作区保存你的材料、卡片和处理记录。少走弯路的具体目录与用法见[包内说明](../skills/Future2046-avoid-pitfalls/README.md)。

## 怎样更新

取得新版发布包并解压，在**新版**根目录重新运行：

```powershell
python -m pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File .\tools\sync_codex_install.ps1
```

同步工具会核对安装目录中的 Skill 文件，不修改你的个人工作区。当前没有自动联网更新能力；对入口说“更新”并不会自行下载新版。

只想重装某个 Skill 时，指定调用名：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\sync_codex_install.ps1 -SkillId future2046-avoid-pitfalls
```

这一操作也会同步入口的候选目录。更新后新建 Codex 对话；仍找不到入口时，在发布包根目录检查安装结果：

```powershell
python tools/verify_codex_install.py --source skills/Future2046-router --target (Join-Path $env:USERPROFILE '.codex\skills\Future2046-router')
```

## 已经知道要做什么

可以跳过入口，直接调用具体 Skill。调用名后面写上任务或材料：

```text
$future2046-avoid-pitfalls 请拆解这篇文稿里的误区：……
```

同一个对话中想继续处理，直接补充材料或反馈即可。需要重新判断该用什么能力时，再输入 `$future2046`。

## Future2046 怎样工作

1. 你提供任务、已有材料和希望得到的结果。
2. `$future2046` 检查哪些正式 Skill 已安装且定义有效，再根据任务选择最少的匹配能力。
3. 它完整读取入选 Skill 的规则，并在当前对话里开始处理。具体 Skill 负责自己的判断、审核、停止条件和结果保存。
4. 你补充新事实或反馈后，它沿用已有信息继续；方向需要调整时重新选择能力。

入口选中了一个 Skill，不代表它的业务流程已经完成。如果缺少必需材料，或没有匹配的已安装能力，它会说明具体缺口。

## Skill 全目录

每项都写明适用时机、可以直接输入的话和主要产出。完整执行方法见对应的包内说明。

### `$future2046`｜统一入口

**什么时候用：** 第一次使用、不确定该选哪个 Skill，或一个目标可能需要多种能力衔接。

**你可以这样说：** `$future2046 我有一批视频文稿，想知道现在能用哪些方法处理。`

**你会得到：** 当前已安装能力的选择理由，以及可以立即开始的处理；缺少关键材料时会指出需要补什么。[入口说明](../skills/Future2046-router/README.md)。

### `$future2046-avoid-pitfalls`｜行业误区与避坑卡

**什么时候用：** 想从文章、书籍、访谈、视频文稿、新闻稿或 Excel 行文稿中拆出有原文依据的误区卡，提前识别行业常见坑、避坑并少走弯路；也适合围绕一个具体行业持续整理资料，建立行业避坑知识库，或查找已有卡片。

**你可以这样说：** `$future2046-avoid-pitfalls 请读取我的工作区，拆解指定文稿。` 或 `$future2046-avoid-pitfalls 我正在研究餐饮行业，请把这些文章和访谈整理成行业避坑误区卡。`

**你会得到：** 按该 Skill 规则处理的误区卡，或符合查询条件的已有卡片；每张卡保留行业分类、标签、来源地址和原文依据，可作为后续行业避坑和观点调用的内容资产。输入、审核与保存方式见[包内说明](../skills/Future2046-avoid-pitfalls/README.md)。

### `$future2046-skill-maker`｜Skill 制作器

**什么时候用：** 想创建新的 Future2046 Skill、改进已有 Skill、检查版本和安装一致性，或准备发布 Skill。

**你可以这样说：** `$future2046-skill-maker 帮我设计一个新的 Future2046 Skill，并先给出方案。`

**你会得到：** 可确认的 Skill 方案、结构和行为验证结果，以及在授权范围内的安装或发布准备。完整规则见[包内说明](../skills/Future2046-skill-maker/README.md)。

## 常见场景

### 1. 不知道该从哪里开始

```text
$future2046 我有一篇文章和几份视频文稿，想把它们变成以后能调用的内容资产。
```

先说明手上的材料和目标。入口会核对现有能力；没有对应 Skill 的部分会如实说明。

### 2. 已经明确要拆误区

```text
$future2046-avoid-pitfalls 请拆解我指定的文稿。
```

直接提供文字、文稿文件或工作区路径。需要保存多篇结果时，按包内说明准备工作区。

### 3. 完成一步后继续

```text
这批卡片已经生成。接下来我想按一个观点查找能用的卡片。
```

在当前对话里补充下一步要求即可；需要重新选择 Skill 时再调用 `$future2046`。

## 使用习惯

- **说清材料和结果。** 给出原文、文件或工作区路径，并说明希望拿到什么。
- **不用重复背景。** 当前对话里已有的信息可以接着使用，只补充新的事实或反馈。
- **区分安装包与工作区。** 更新 Skill 时保留自己的工作区；个人资料不放进安装包。
- **确认实际执行情况。** 入口推荐了某个 Skill，与该 Skill 已完成处理是两件事。
